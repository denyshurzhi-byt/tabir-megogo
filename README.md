# «Табір нових можливостей» — прем'єра на MEGOGO

Лендинг SKELAR × БФ «Діти Героїв»: один екран, таймер до відкриття перегляду (19.10.2026 00:00 за Києвом) і кнопка донату на збір BACK TO SCHOOL.

Статичний сайт без збірки: `index.html` + `assets/`. Деплой — Vercel (Framework Preset: Other).

Налаштування — на початку `<script>` в `index.html`:
- `PREMIERE` — дата й час відкриття перегляду
- `DONATE_URL` — посилання на збір
